# AsyncTaskManagerWpf

A WPF desktop task manager built with .NET Framework 4.8.

## Features

- Add, delete, save, and load tasks
- Filter tasks by all, active, or completed status
- Search tasks by title or description
- Persist task data as JSON under the user's local application data folder

## Requirements

- Windows
- Visual Studio with .NET Framework 4.8 targeting pack
- NuGet package restore enabled

## Getting Started

1. Open `AsyncTaskManagerWpf.sln` in Visual Studio.
2. Restore NuGet packages if prompted.
3. Build and run the `AsyncTaskManagerWpf` project.
